## Resolution during implementation

1. Prefer skills already available in the agent's catalog. Read the actual files and record the installed revision when identifiable. If it differs from this revision, check the contracts used against the project's packages.
2. If skills are missing, use the pinned links above and resolve relative reference links within the same revision. If local files are needed, obtain the source in a temporary directory while preserving its tree.
3. If the required instructions and references are inaccessible, report the missing dependency and request installation or access. Do not generate code claiming to follow a skill that has not been read.

To explicitly install the three skills in the destination project, run from that project:

```bash
npx skills add Javiani/agent-skills --skill ui-clean-arch jails jails-stdlib
```

The installer allows agent selection. This command follows the version available upstream at installation time; the links above identify the revision reviewed by jails-ai. Preserve the lockfile generated by the installer when applicable.

## Composition and updates

This file is jails-ai's reference catalog. It is not a dependency manifest and does not install skills automatically. `dependencies.tools` in `agents/openai.yaml` is intended for MCP tools; do not use it to declare dependencies between skills.

Keep detailed contracts upstream. When updating this revision, reread the three skills and affected references, check compatibility, and update all links together. The reviewed `jails-stdlib` skill documents library version 2.2.3; check the version actually installed before applying its examples.

If copies of the skills are distributed in the future, include their original license and attribution. jails-ai currently provides references without redistributing those files.
